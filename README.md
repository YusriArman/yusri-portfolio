# Yusri Arman, portfolio

Single-page portfolio built with React, Vite, TypeScript, plain CSS and Motion.

- Words, links, projects, roles and events: `src/content/`
- Colours, fonts, spacing: `src/styles/tokens.css`
- Photographs: originals in `photo-originals/`, optimised copies in `public/images/` (run `npm run photos`)
- Résumé: `public/resume/`

```bash
npm install
npm run dev      # local preview at http://localhost:5173
npm run build    # production build in dist/
npm run photos   # optimise the photographs in photo-originals/
```

See `MAINTENANCE.md` for how to edit and publish, and `CONTENT-CHECKLIST.md` for what is still missing.
