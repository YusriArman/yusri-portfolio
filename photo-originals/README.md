# Photo originals

Put your original, full-size photographs here. You do not need to resize, crop or rename them. JPEG, PNG, HEIC (iPhone), WebP and TIFF all work.

| Folder | What goes in it |
| --- | --- |
| `portrait/` | One portrait of you |
| `projects/elysium/` | One screenshot of the Elysium platform |
| `projects/moneytalks/` | One screenshot of MoneyTalks |
| `leadership/president/` | One photograph for the presidency card |
| `events/orientation-party-2026/featured/` | One wide photograph of the event |
| `events/orientation-party-2026/gallery/` | Three to six more photographs. They appear in filename order. |

Then run:

```bash
npm run photos
```

This writes optimised copies into `public/images/` and leaves the originals untouched. See `CONTENT-CHECKLIST.md` for suggested subjects and shapes.

The files in this folder stay on your computer. They are not saved to Git and are never published, so keep your own backup of them.
